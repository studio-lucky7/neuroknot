# 사전 실험 계획

기준: origin/fix/pred-review-hardening, d17ac32. 운영 코드는 변경하지 않는다.

- 기존 기본 지문 실험과 문항 실험을 먼저 재현한다.
- 연구 규모: 시드당 사용자 60명, 지문 60개, 사용자당 16라운드/48응답.
- 주 실험 learning_rate=0. 별도 강건성 확인은 기존 0.01 가정.
- 탐색 시드: 11, 29, 47. 검증 시드: 101, 211, 307, 401, 503.
- 기본 V1, Random, 취약 가산점 제거, 커버리지 가산점 제거, 두 가산점 제거,
  콜드스타트 제거, 목표 적합도만(두 가산점과 콜드스타트 제거)을 비교한다.
- SelectionConfig, EloModel 생성자만 주입하여 운영 수식/기본값을 보존한다.
- 후보는 experiment.variants()에 명시한 단변량 설정이다. 조합 탐색은 하지 않는다.
- 튜닝 종료 후 비-Ablation 후보 중 공통 평가의 최종 확률 MSE가 가장 낮은 두 개와
  커버리지 격차가 가장 낮은 한 개를 frozen_candidates.json에 고정한다.
  동률은 각각 커버리지 격차, 공통 확률 MSE로 해소한다.
- 검증에서는 모든 Ablation과 고정 후보만 평가한다. 검증 결과로 재튜닝하지 않는다.
- 모든 정책에 별도 RNG로 만든 동일한 미학습 문항 40개(스킬당 10개)를 제공한다.
  0/6/48 응답 직후 예측만 읽고 갱신하지 않는다. 모델 등록에는 ID, 스킬, 별점, 온보딩만 전달한다.
- 실제 잠재 θ/b, 공통 평가 응답, 미래 응답은 모델 갱신/정책 선택에 전달하지 않는다.
- 예측 지표: AUC, log loss, Brier, ECE(등간격 10 bins), 실제 확률과의 MSE,
  기대 Brier=p_true(1-p_true)+(p_pred-p_true)^2. θ 오차와 b 오차는 evaluator에서 계산한다.
- 관측 구간: 첫 6개, 전체, 31번째 이후. 48개를 충분한 수렴으로 보장하지 않는다.
- 정책 지표: 고정 기준 .7에 대한 예측/실제 확률 거리, 적용 목표 거리, 실제/초기 정답률,
  스킬 커버리지 격차. 목표를 바꾼 후보도 공통 .7 기준을 함께 유지한다.
- 사용자별 지표 원자료와 p10/p50/p90, 시드별 평균/표본분산/SD/Student-t 95% CI,
  동일 시드 V1 대비 paired 차이 CI를 저장한다. 응답을 독립 반복으로 취급하지 않는다.
- 공통 heldout의 b는 prior만 평가하므로 훈련 문항 b 복원력을 별도로 보고한다.
- 합성 1PL 일치, 별점의 실제 b 기반 생성, 짧은 궤적, 노출별 선택 편향, 적은 시드,
  학습량 가정의 한계를 명시한다. 정답률 상승을 학습 효과로 해석하지 않는다.
